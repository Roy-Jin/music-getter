## Features

- 🎵 **NetEase Cloud Music** — Built specifically for NetEase Cloud Music with complete music resource acquisition capabilities
- 🔍 **Flexible Search** — Search songs, albums, artists, and playlists with flexible control over type, pagination, and result count
- 📦 **Batch Download** — Download entire albums or playlists with one command, supporting custom output directories and audio bitrates
- 📝 **Lyrics & Covers** — Optionally download LRC lyrics files and cover images to enrich your music collection
- 🔌 **Programming Interface** — Provides a complete Node.js API for integration into your own projects
- 🌐 **Online Preview** — Preview songs directly in your browser before deciding to download

## Quick Start

### Install

```sh
npm install -g ncmget
```

Or use without installing:

```sh
npx ncmget --help
```

### Usage

```sh
ncmget <command> [options]
```

For detailed documentation, please refer to the [Introduction](https://roy-jin.github.io/ncmget/introduction).

## Build from Source

```sh
git clone https://github.com/Roy-Jin/ncmget.git
cd ncmget
npm install
npm run build
```
