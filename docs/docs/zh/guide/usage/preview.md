# 预览歌曲

使用 `preview` 命令在浏览器中打开歌曲的在线播放页面，试听后再决定是否下载。

## 基本用法

```sh
mg preview <song-id> [options]
```

`song-id` 是歌曲在音乐平台上的唯一标识符。

### 示例

```sh
# 在默认浏览器中预览歌曲
mg preview 1372188635
```

## 选项说明

| 选项 | 说明 | 默认值 |
|------|------|--------|
| `-s, --server <source>` | 音乐平台 | `netease` |
| `-a, --api <url>` | 自定义 API 地址 | — |

## 使用场景

- **试听歌曲**：在下载前先试听，确认是想要的版本
- **确认音质**：通过在线播放判断音质是否满足需求
- **快速访问**：快速在浏览器中打开歌曲页面

## 注意事项

- 该命令会自动打开系统默认浏览器
- 预览 URL 来自 Meting API 返回的播放地址
- 预览功能仅支持 HTTP/HTTPS 协议的 URL
