# lrc

下载歌词文件。

## 用法

```bash
ncmget lrc <id...> [选项]
```

## 参数

| 参数 | 描述 |
|------|------|
| `<id...>` | 歌曲ID，支持多个ID（空格分隔） |

## 选项

| 选项 | 默认值 | 描述 |
|------|--------|------|
| `-o, --output <output>` | `"./"` | 输出目录 |
| `-f, --format <format>` | `"{name} - {artist}"` | 文件名格式模板 |

## 示例

### 下载单首歌词

```bash
ncmget lrc 3374579108
```

### 下载多首歌词

```bash
ncmget lrc 3374579108 111111
```

### 指定输出目录

```bash
ncmget lrc 3374579108 -o ./lyrics
```

### 自定义文件名格式

```bash
ncmget lrc 3374579108 -f "{artist} - {name}"
```

## 输出

下载的歌词文件将以 `.lrc` 格式保存到指定目录。歌词文件包含原文歌词和翻译歌词（如有）。
