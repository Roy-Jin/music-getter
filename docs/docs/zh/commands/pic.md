# pic

下载封面图片。

## 用法

```bash
ncmget pic <id...> [选项]
```

## 参数

| 参数 | 描述 |
|------|------|
| `<id...>` | 封面图片ID，支持多个ID（空格分隔） |

## 选项

| 选项 | 默认值 | 描述 |
|------|--------|------|
| `-o, --output <output>` | `"./"` | 输出目录 |
| `-s, --size <size>` | `"300"` | 图片尺寸（像素） |
| `-f, --format <format>` | `"{name} - {artist}"` | 文件名格式模板 |

## 示例

### 下载封面图片

```bash
ncmget pic 3374579108
```

### 下载多张封面

```bash
ncmget pic 3374579108 111111
```

### 指定输出目录

```bash
ncmget pic 3374579108 -o ./covers
```

### 指定图片尺寸

```bash
# 下载 800x800 的高清封面
ncmget pic 3374579108 -s 800
```

### 自定义文件名格式

```bash
ncmget pic 3374579108 -f "{album}"
```

## 输出

封面图片将保存到指定目录，文件格式取决于原始图片格式（通常为 `.webp` 或 `.jpg`）。
